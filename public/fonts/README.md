# Fontes

O site usa três fontes comerciais. Coloca aqui os ficheiros **.woff2** com
exatamente estes nomes e o site passa a usá-los automaticamente:

```
LovelaceText-Regular.woff2
LovelaceText-Bold.woff2
Garet-Regular.woff2
Garet-Bold.woff2
TheSeasons-Regular.woff2
TheSeasons-Bold.woff2
```

Onde é usada cada uma (retirado do rascunho original):

| Fonte            | Onde                                                                 |
| ---------------- | -------------------------------------------------------------------- |
| **Lovelace Text** | Títulos grandes — "Rosarinho e Manel", "Missa", "Copo d'água", "Lista de presentes", "Onde ficar?", os anos (2018/2022/2026) e os destinos da lua de mel |
| **Garet**         | Menu, datas, horas e todo o texto corrido das secções verde/azul     |
| **The Seasons**   | Formulários (etiquetas, botões) e o texto do IBAN                    |

Se tiveres apenas `.ttf`/`.otf`, converte para `.woff2` (por exemplo em
<https://cloudconvert.com/ttf-to-woff2>) — fica bastante mais leve.

**Enquanto não houver ficheiros aqui**, o site cai automaticamente para
substitutos parecidos do Google Fonts (Playfair Display, Poppins e Cormorant
Garamond), por isso nada fica partido.
